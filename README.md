**Header & Badges: Badge React 19, TypeScript, Vite, Tailwind CSS v4, dan lisensi Apache 2.0.

Daftar Fitur Lengkap:

📱 Data Siswa & Presensi Kelas: Real-time ratio, quick toggle (H, S, I, A), filter, dan ekspor CSV.

📋 Lembar Detail Siswa (Bottom Sheet): Riwayat kehadiran 5 hari, persentase kehadiran, kontak orang tua via WhatsApp, dan catatan wali kelas.

👨‍🏫 Data Guru & Staf: Live session status KBM, metrik bento, kontak WA, Agenda Ajar, Surat Tugas (SPT), dan plotting guru inval pengganti.

🔍 Filter Presensi Guru & Staf: Rentang tanggal, switch status, unit kerja (RPL, TKJ, DKV, Normatif), dan penugasan piket.

📢 Pengumuman & Berita Civitas: Urgent alert cuaca ekstrem, kategorisasi berita, tombol bookmark, like siswa bangga, dan modal publikasi rilis pengumuman.

📊 Dashboard Eksekutif: 4 KPI Cards, grafik tren kehadiran mingguan (Siswa vs Guru), live kelas berlangsung, dan timeline log aktivitas terkini.

⚡ Simulasi Scanner RFID / QR Code & Gateway WhatsApp: Simulasi tap kartu dengan laser scan & audio chime Web Audio API serta broadcast notifikasi orang tua.

Dokumentasi Folder /desain: Penjelasan kegunaan desain.md, index.html, style.css, dan script.js sebagai prototipe mandiri yang dapat dibuka langsung di peramban tanpa node_modules.

Sistem Desain & Palet Warna: Panduan warna identitas Telkom Red (#E60012), Plus Jakarta Sans, dan Inter.

Panduan Instalasi & Build: Langkah kloning git, npm install, npm run dev, npm run build, dan panduan kontribusi.
